# AI-радар

Невеликий веб-проєкт: каталог нових AI-сайтів на основі публічного API [FreeSerp](https://freeserp.ai/docs.php) (без ключа та реєстрації). Використовується індекс `index=sites` (головні сторінки сайтів) і ніша AI (`ai_startups=1`).

Весь проєкт — один файл `ai-radar.html` (HTML + CSS + JavaScript, без збірки та залежностей).

## Що зроблено

- **Каталог.** Картки сайтів: домен, заголовок, короткий опис (`ai_summary`), AI-ніші, стек, дата, коли сайт вперше підтверджено живим (`went_live`), DR.
- **Пошук і фільтри.** Текстовий запит (`q`), 15 AI-ніш (`ai_categories`), стек (`ai_source`), сортування: нові / старі / за DR.
- **Порівняння.** Можна позначити до 3 сайтів і побачити їх поруч у таблиці.
- **Про проєкт.** Вкладка з планом сайту: мета, аудиторія, сторінки та структура.
- **Резервний режим.** Якщо живий запит до API не вдався (таймаут 7 с, мережа, CSP), сторінка показує вбудований знімок відповіді API і попереджає про це.
- **Інше.** Світла й темна теми (за системними налаштуваннями), адаптивна верстка, екранування HTML у даних з API.

## План сайту

- **Мета:** швидко знаходити й оцінювати нові AI-продукти без ручного серфінгу.
- **Аудиторія:** засновники й продакт-менеджери (аналіз конкурентів), розробники (пошук інструментів), інвестори та журналісти (моніторинг новинок).
- **Структура** (одна сторінка, три вкладки): Каталог → Порівняння → Про проєкт.

## Як запустити

1. Збережіть `ai-radar.html` на комп'ютер.
2. Відкрийте файл у браузері (подвійний клік). API відкрите для CORS, тож запити працюють і з `file://`.
3. Або запустіть локальний сервер у теці з файлом:
   ```bash
   python3 -m http.server 8000
   # потім відкрийте http://localhost:8000/ai-radar.html
   ```

Для розміщення в інтернеті достатньо покласти файл на будь-який статичний хостинг (GitHub Pages, Netlify тощо). Хостинг не повинен забороняти запити до `freeserp.ai` (наприклад, через Content-Security-Policy).

Основний запит, який робить сторінка:

```
GET https://freeserp.ai/api.php?ai_startups=1&sort=went_live&order=desc&size=24
    [&q=…][&ai_categories=…][&ai_source=…]
```

## Чого не встигли / обмеження

- **Живий режим не перевірено.** Опублікована версія працює лише на знімку: середовище публікації не дозволяє запити до сторонніх сайтів. Запит до API складено за документацією, але в живому режимі я його не запускав.
- **Знімок невеликий і не повний.** Це 12 сайтів з однієї ніші («AI Agents & Autonomous»), отримані з API у вересні 2026. У резервному режимі працюють пошук, ніша й стек, а сортування — ні.
- **Немає пагінації.** Завантажується лише перші 24 результати, хоча API дозволяє `from`/`size` до 10 000.
- **DR часто порожній.** Для нових доменів API його ще не обчислює, тому сортування за DR на таких даних мало корисне.
- **`went_live` ≠ дата запуску.** Це дата, коли сайт уперше підтверджено живим.
- **Немає тестів, кешу й обробки помилок крім перемикання на знімок.** Повторні запити не кешуються.
- **Стан не зберігається.** Вибрані для порівняння сайти і фільтри губляться після перезавантаження сторінки.
- **Мова.** Інтерфейс українською, а описи сайтів з API англійською (та іншими мовами оригіналу).

## Що доробили б далі

1. Перевірити живий режим і додати кнопку «Завантажити ще» (пагінація через `from`).
2. Додати фільтри за DR (`dr_min`/`dr_max`) і датою (`from_date`/`to_date`), вибір TLD.
3. Зберігати фільтри в URL (`?q=…&cat=…`), щоб ними можна було ділитися, а вибрані для порівняння сайти — у `localStorage`.
4. Додати вкладку «Новинки за тиждень» зі згрупованими за нішами сайтами і лічильниками зі `?stats=1`.
5. Додати переклад описів українською (наприклад, через LLM-запит) і окремий перемикач мови інтерфейсу.
6. Додати кешування відповідей у `sessionStorage` і прозорі помилки (повтор із затримкою при 502).
7. Додати експорт результатів і порівняння в CSV.
8. Додати в запити параметр `agent=` (вже передається як `AI-radar/1.0`) та контакт `email=`/`project=`, як радить документація.
9. Розбити код на модулі та додати кілька автотестів для логіки фільтрації.

## Джерело даних

[FreeSerp API](https://freeserp.ai/docs.php) — безкоштовний, без ключа. Будь ласка, не робіть більше кількох запитів на секунду.
